## Protocol

```
all labelled TCGA samples
  |-- LOCKED TEST (stratified; created once; ids stored in data/processed/locked_split_*.json; every use logged)
  '-- DEVELOPMENT SET
        |-- nested CV: outer 5 folds x 2 repeats; inner 5-fold RandomizedSearchCV; calibration and decision threshold fit inside each training fold
        |-- choices: feature strategy -> imbalance handling -> learner / ensemble -> calibration (one-SE rule, stability gate)
        '-- chosen procedure refit on the whole development set -> locked test (once) -> external cohort (refit on shared genes, once)
```

Data: 555 labelled patients (MSI-H prevalence 16.0%); development 416, locked test 139. 37 TCGA patients with no MANTIS score are excluded (they used to be mislabelled MSS; see `ML_AUDIT.md`).

## Leakage and integrity checks

* Label-permutation canary (nested CV with shuffled labels): AUC 0.461, 0.530 → mean 0.495 (must be ≈ 0.5): **pass**.
* Leave-sites-out CV (whole tissue-source sites held out): AUC 0.868 ± 0.055, accuracy 0.862 — compare with random-split CV AUC 0.877.
* Development/test sample overlap: 0; patient overlap: 0 (one sample per patient).
* Scaling, feature selection, PCA, SMOTE, signature z-scoring, calibration and the decision threshold are steps of the fitted procedure (unit-tested in `tests/test_model_selection.py`).
* Locked-test usage log: 3 scoring run(s) of the same final code (an earlier run stopped in the explainability step after scoring, which was fixed without touching any model, feature or threshold choice). Details in `data/processed/locked_split_*.json`.

## Where the limit comes from

* Prevalence is 16%: always predicting the majority class already scores ~84% accuracy, so accuracy near 88% means the model adds a few points, and AUC/MCC/balanced accuracy are the honest summaries.
* The locked test set has few positives, so every positive-class number (sensitivity, F1, MCC) carries a wide interval.
* The 35-gene ferroptosis panel is the ceiling for the core model; adding mismatch-repair genes lifts CV accuracy to about 0.93 (see the Model Lab). The whole-transcriptome re-run under the corrected labels and locked protocol did NOT complete, so no whole-transcriptome figure is reported; an earlier whole-transcriptome result predates the corrected labels and is deliberately not quoted.

Locked test (held-out cell lines): MAE 0.866 (95% interval 0.76–0.97), RMSE 1.128, R² 0.818, Pearson 0.908, Spearman 0.879. Per-drug-mean baseline on the same cells: MAE 0.868, R² 0.815 (+0.2% MAE vs baseline).

**Does expression add anything beyond drug identity?** Against predicting each compound's average, the champion changed fold-level MAE by +0.061 ± 0.038 (positive = better; better in 5 of 5 folds) and by +0.2% on the locked-test cell lines. Treat the drug-response model as 'which compound is this, adjusted a little for the cell line': the cell-line-specific signal is small relative to its noise.

Note: boosted-tree models that use a one-hot drug representation with small trees (`hist_gradient_boosting`, `gradient_boosting`) cannot isolate 268 compounds with the permitted tree sizes; that is a limit of this representation, not necessarily of the algorithm.
