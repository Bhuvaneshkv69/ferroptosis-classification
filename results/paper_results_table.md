**Observation (reported, not corrected): cross-validated vs locked-test discrimination.** For every model the locked-test AUC is below the cross-validated AUC, while accuracy barely changes (accuracy is dominated by the majority class).

| Model | CV AUC ± SD | Locked-test AUC | Test AUC 95% interval | Gap (CV − test) | Gap in CV SDs | Accuracy CV → test |
|---|---|---|---|---|---|---|
| Ferroptosis Core Classifier | 0.880 ± 0.028 | 0.832 | 0.73–0.92 | 0.049 | 1.7 | 0.877 → 0.863 |

| Extended Molecular Model | 0.924 ± 0.034 | 0.886 | 0.78–0.97 | 0.037 | 1.1 | 0.931 → 0.921 |

The gap is 1.7 CV SDs for the Ferroptosis Core Classifier, 1.1 for the 35-gene + MMR Extended Model and 1.1 for the Extended Molecular Model. With only 22 MSI-H test patients the test AUC interval is wide, so this may be sampling variation or mild optimism of the cross-validated discrimination; it is flagged as a limitation, not a finding. Note also that the 53-feature model's higher CV AUC than the 39-gene model's is not reproduced on the locked test (equal test AUC).

**External cohort.** External-cohort data were evaluated separately from the primary locked-test evaluation and were not used for model selection or the primary performance claims. (CPTAC-2 colon: 110 samples, 105 with a cohort MSI_STATUS label and expression: 81 MSS, 24 MSI-H; the cohort's own MSI call, whereas TCGA labels are MANTIS ≥ 0.4; models refit on the shared genes: core 28 of 35, core_plus_mmr 32 of 39, extended_molecular 43 of 53.) Its results are supplementary and excluded from the primary performance claims.

Only the Ferroptosis Core Classifier is a ferroptosis-gene classifier. The 35-gene + MMR Extended Model and the Extended Molecular Model add mismatch-repair genes (MLH1, MSH2, MSH6, PMS2) and, for the latter, 14 immune genes; mismatch-repair deficiency defines MSI-H, so their higher accuracy is associated substantially with those genes and must not be attributed to ferroptosis genes.
