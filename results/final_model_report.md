### Audit trail (brief)

* The locked test set was scored and logged 7 times in total: once per authoritative classifier, plus the baseline reproduction and the earlier single-model benchmark runs. Every authoritative model has exactly one logged scoring, and its stored final metrics equal that logged scoring (maximum difference 6e-17).
* One crash occurred while building the extended-feature models: a floating-point rounding error (a probability of 1.0000000000000002) in the cross-validation-only calibration study, **before** the locked test was touched for that model. Probabilities are now clipped to [0, 1] in the metric function (numerical safety only). The rerun resumed from cached cross-validation, selected the same candidate on cross-validation alone, scored the locked test once, and was not used to tune anything. Later file timestamps for that model reflect a four-hour leakage check that ran after the scoring.
* Caveats: the 35-gene and 39-gene results were produced before the clipping fix and were not recomputed (the fix can only change a probability that exceeded 1 by about 1e-16). Every candidate in each screening table was scored once on the locked test for reporting; selection used cross-validation only. No unlogged re-scoring was found.

### Wording notes verified against the repository

* **External cohort.** External-cohort data were evaluated separately from the primary locked-test evaluation and were not used for model selection or the primary performance claims. Accounting (re-derived from the stored files): 110 CPTAC-2 samples, 105 with an MSI_STATUS label and expression (81 MSS, 24 MSI-H), 5 without a label. The cohort's own clinical MSI_STATUS call (MSS / MSI-H); the TCGA training labels are MANTIS >= 0.4, so the two label definitions differ. docs/DATASET.md describes the cohort as independent (different consortium and patient population). This audit verified only that no sample or patient IDs overlap with the TCGA table. Models are refit on the shared genes core 28 of 35, core_plus_mmr 32 of 39, extended_molecular 43 of 53.
* **35-gene panel.** Derived from the literature; no gene was chosen using this study's expression data or MSI labels. Union of 8 core-mechanism genes (a published mechanistic review) and 27 genes from four published colorectal-cancer ferroptosis prognostic/metastasis signatures; src/ferroptosis.py reads only the literature table (data/ferroptosis_genes_literature.csv). Caveat: docs/DATASET.md states that TCGA COADREAD is the cohort used by all four source signature papers, so the panel is literature-derived but not independent of the TCGA cohort (the original selection was for prognosis/metastasis, not MSI). Not claimed: that the list was fixed before any modelling: the repository does not prove it (the gene files first appear in the 2026-09-06 baseline commit).
* **Intervals.** "95% interval" = class-stratified nonparametric percentile bootstrap (2,000 resamples of the locked-test patients, seed 0, 2.5th–97.5th percentile; test-set sampling variation for a fixed fitted model and fixed predictions; not training variability). Drug-response MAE interval: cluster (cell-line) nonparametric percentile bootstrap (1,000 resamples of whole cell lines). "±" on cross-validation metrics: standard deviation (ddof=1) of the per-fold metric across the outer folds (5 folds x 2 repeats = 10); descriptive spread, not an interval; folds from repeated cross-validation overlap and are not independent.

## 14. Limitations

* Only 22 MSI-High patients in the locked test set: every positive-class metric has a wide interval.
* The locked test was used only for reporting and for the single CV-chosen candidate's confirmation; it cannot be reused for further tuning.
* External validation (CPTAC-2) uses a refit on the genes available in that cohort, and a different platform/batch.
* The whole-transcriptome re-run (corrected labels, locked protocol, nested leakage-safe selection) was stopped before finishing because of its runtime; no whole-transcriptome result is reported, and an earlier pre-correction figure is not quoted.
* Extended-model gains partly reflect that mismatch-repair genes are mechanistically linked to the MSI label itself; they are not ferroptosis biology.
* Best non-core feature set by CV accuracy: Extended Molecular Model (53 features) (0.931).
* The 35-gene panel is literature-derived but not independent of TCGA (the source signature papers used TCGA COADREAD); it was not chosen using this study's data or MSI labels.
* The external cohort uses its own MSI_STATUS call and models refit on shared genes; it does not evaluate the served models directly and is excluded from the primary claims.
* Locked-test AUC is below the cross-validated AUC for all three classifiers (see the observation above).
* The core ensemble was promoted on its predefined CV gate (AUC gain about +0.004); its locked-test accuracy is not higher than the best single model's.
* Research use only. Outputs are model classifications and computational drug-response estimates, not diagnoses or treatment recommendations.
